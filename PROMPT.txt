做一个可独立部署的放射性衰变链核算服务，让上游把一条线性核素链的衰变常数与初始核数交给它，沿给定时刻算出各核素核数与活度，并报告母体剩余与原子总数。这是一个纯服务端的核素动力学计算组件，不涉及辐射监测大屏、前端页面或账户体系。

链与方程：链为 N1 到 Nk 的单向线性衰变，第 i 个核素的变化率等于上一核的产生项减去自身衰变项；第一个核没有产生项。末核的衰变常数允许为零（稳定终点）或为正（继续衰变）。活度等于该核衰变常数乘以该核核数；稳定核的活度必须为零。衰变常数为负、初始核数为负、链长度少于 2 或超过 12、时刻为负或含非有限值，都要在计算前返回可区分的结构化错误，指明哪一个核、哪一个参数不合法。相邻两个衰变常数几乎相等时，不得出现除零或数值爆炸，仍须给出确定、有限的核数。

求解：调用方可给出一组指定时刻，或给出起止时刻与步数由服务生成均匀网格。同一组衰变常数与初值下，零时刻必须精确回到初值。步数超过上限要返回错误。输出每个时刻各核的核数、活度，以及该时刻仍在链上的原子总数；若末核稳定，还要给出已迁入稳定终点的核数，使「链上剩余加稳定终点」与初始总原子对得上。

必须守住的行为：全部衰变常数为正时，链上总核数必须随时间严格下降，且零时刻附近的下降率等于第一个核的衰变常数乘以其初值。长期足够大的时刻：若末核稳定，稳定核核数必须趋于初始总原子，其余核趋于零；若所有核都不稳定，全部核数趋于零。当子体衰变常数远大于母体时，短寿命子体核数应逼近母体衰变常数乘母体核数再除以子体衰变常数。母体活度只随自身指数下降，不因子体公式改错而跟着摆动。把所有初值同时加倍，任意时刻各核核数与活度都必须加倍。请预置一个可直接调用的算例：截取 2 到 4 个核、时间短到母体几乎不变，子体生长应与母体衰变常数乘母体初值乘时间同量级。

输入与异常：缺字段、非数值、核素顺序与衰变常数长度不一致、把稳定核的衰变常数写成负零之类的矛盾输入，都要返回带说明的可读错误，而不是算出一个看似正常其实错误的数，也不能直接崩溃。批量核算中某一组非法时，要指出是第几组、哪一个核、哪个参数的问题，其余各组照常返回结果。

服务能力：除单条链在一组时刻上的求解外，支持一次提交多条链的批量核算，并把每次核算请求与结果持久化保存，供之后按条件查询历史记录。对外提供时刻求解接口、均匀网格接口、批量接口、历史查询接口，以及一个回显链长上限与数值容差配置的查询接口。服务需暴露基本运行状态供监控采集，且并发处理多请求时结果互不干扰、历史记录不错乱。

技术上用 Java 实现，基于 Spring Boot 提供 HTTP 服务，持久化用数据库，提供 Docker Compose 一键构建并启动服务与其依赖。代码请合理拆分为多个模块/文件，链模型、时刻求解、活度与守恒校验、输入校验与持久化不要堆在同一个文件里。附带能验证上述核算规则的自动化测试，覆盖零时刻回到初值、全不稳定时总核数下降且开端下降率正确、末核稳定时长期原子守恒、全不稳定时长期全部趋于零、短寿命子体逼近母子活度平衡、母体活度只随自身指数下降、初值加倍则结果加倍、相邻衰变常数接近时结果仍有限、非法参数被拒、批量部分失败其余成功、历史持久化正确、以及并发多请求互不串扰。
